How to read this report

Recorded means the source log contains the value. Calculated means derived directly from recorded values using a stated formula. Estimated means inferred from incomplete or indirect evidence. Unavailable means the log does not contain enough data. This first milestone reports decoded channels and conservative findings; it does not claim exact failure causation, airborne time, coordinates, vibration health, or individual motor RPM without supporting fields. A Blackbox motor command is not measured motor speed.
